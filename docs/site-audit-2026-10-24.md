# ZAIHAI 全站自检记录（2026-10-24）

## 范围与方法

- 前台：桌面及 390px 手机视口检查首页、导航抽屉、产品、新闻、博客、公司、联系、支持及七种语言首页；检查图片加载、页面横向溢出、跳转、视频播放、联系入口。
- SEO / AI：读取 robots、站点地图、页面 canonical、H1、索引指令与结构化数据；对站点地图列出的 URL 做只读自动核查。
- 后台：登录后检查 28 个主要页面、10 个手机端页面及日/周/月/年统计切换；核对订单、行为、搜索数据、定时任务和后台 API 登录保护。
- 数据链路：使用明确标记的测试咨询单执行一次前台提交，核对 API、邮件发送状态与后台通知记录。测试记录保留在持久化审计中，不删除生产数据；业务报表排除该测试标记。

## 已确认并修复

1. 产品导航在鼠标进入或聚焦时已展开，随后点击又切换为关闭。点击改为保持展开；本地浏览器复测可打开菜单、选择商品并在跳转后收起。
2. 后台业务聚合缓存超过 Next.js 2 MB 限制，线上运行日志证实写入失败，导致后台反复读取完整持久化事件集。聚合结果改为 gzip 编码缓存、请求内复用，并保留 30 秒刷新期。
3. 后台测试数据识别原先把多个 ID 拼成一个字符串，后面的测试标记未被识别。现在逐字段识别，测试咨询单仍保留原始审计记录，但不计入业务 KPI。
4. 收入漏计 `completed` 已付款订单；转化率把重复咨询或支付事件当成多次转化；来源与国家图把非访问事件、订单混入访问统计。已按真实访问会话及唯一访客统一口径。
5. 新闻自动采集已按既有配置停用，但同步页仍依据历史发布日期显示“正常”。现明确显示停用状态，第三方博客任务不变。
6. 首页结构化数据宣称存在不支持的站内搜索接口，已移除该 SearchAction。
7. 后台默认公司地址写成 Building 1，与前台不一致。公司确认实际为 Building 2；后台生产设置已保存 Building 2，代码默认值同步更正。

## 核查结果

- 站点地图：5 份地图、200 个 URL；本次抓取均返回 HTTP 200，且有自指 canonical、H1、可索引指令。
- 桌面与手机：受检页面无文档级横向溢出或加载失败图片；首页视频可播放，视频资源支持 HTTP 206 分段请求。
- 后台：受检页面无外层溢出或损坏图片；日/周/月/年筛选返回不同的真实统计，切换约 1–2 秒。后台分析及访客 API 未登录时返回 401。
- 咨询链路：一次带测试标记的提交返回 HTTP 200 与 `emailStatus: sent`，后台可见对应邮件发送及审计记录。此结果证明应用和发信服务接受并记录发送；收件邮箱最终投递仍需邮箱侧独立核对。
- 自动化：43 项测试通过；TypeScript 检查通过；生产构建通过。
- Google 同步：现有定时配置保留每周一 Google Search Console 同步及站点地图健康检查；搜索控制台索引量与排名属于 Google 后续抓取和判断，部署不能保证即时收录。

## 内容与外部平台边界

- 非英语页面仍有一些英文营销正文；七种语言的 canonical / hreflang 可用，但完整人工本地化需要经确认的专业译文，不能用未经审核的机器文案冒充已完成。
- 首页“+40% / +35% / +50+”为现有设计内容，尚未取得可核验的业务证据。本次为保留用户指定的首页模板未改动这些宣称；对外使用前应提供证明或批准替换为可证实的内容。
- Google Search Console 的实际收录结果、邮件收件箱投递、支付服务的真实扣款及订单履约属于外部系统/真实交易，不能通过只读或测试访问假称已验证。
